# data

Rescued personal data lands here. Nothing in this folder is committed, apart
from this file.

| Path | What goes here |
| --- | --- |
| `data/mealime/` | Output of `tools/mealime-export`. See its README. |
| `data/nyt/` | Output of `tools/nyt-export`, plus `nyt_recipe_box.json`. |
| `data/bookmarks.html` | Chrome bookmarks export of open recipe tabs, for the bulk URL import. |

Keep a backup of `data/mealime/` somewhere off this machine. Mealime deletes all
account data on October 21, 2026 and there is no second chance to fetch it.
